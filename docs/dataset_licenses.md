# Dataset Licenses
Each observational source shipped inside `copernican/datasets/` lists
its own usage terms via `metadata_*.yml`. The Copernican also
aggregates the license texts for runtime dependencies in
[`licenses/THIRD_PARTY_LICENSES.md`](../licenses/THIRD_PARTY_LICENSES.md)
and under [`licenses/`](licenses/).
The Union Through UNITY 2000 SNe sample (Union3) is available under an MIT
License authored by David Rubin. Its license is copied into
[`licenses/Union3-MIT.txt`](../licenses/Union3-MIT.txt) so the complete notice
travels with the repository even if the dataset is redistributed separately.
When using Union3 in publications cite Rubin et al. (2025) alongside
Copernican per AGENTS.md requirements.
