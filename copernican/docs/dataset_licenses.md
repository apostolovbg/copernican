# Dataset Licenses

Each observational source shipped inside `data/` lists its own usage terms via
`metadata_*.yml`. The Copernican Suite also aggregates the license texts for
runtime dependencies in
[`licenses/THIRD_PARTY_LICENSES.md`](https://github.com/apostolovbg/copernican/blob/main/../licenses/THIRD_PARTY_LICENSES.md)
and under [`licenses/`](https://github.com/apostolovbg/copernican/blob/main/licenses/).

The Union Through UNITY 2000 SNe sample (Union3) is available under an MIT
License authored by David Rubin. Its license is copied into
[`licenses/Union3-MIT.txt`](https://github.com/apostolovbg/copernican/blob/main/../licenses/Union3-MIT.txt) so the complete notice
travels with the repository even if the dataset is redistributed separately.
When using Union3 in publications cite Rubin et al. (2025) alongside the
Copernican Suite per AGENTS.md requirements.
